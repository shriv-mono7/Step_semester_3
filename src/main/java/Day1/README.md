# Week 1 - Java Basics and Problem Solving

## Class Problems

### 1. BMI Calculator
- Accepts height and weight
- Calculates BMI
- Uses conditional logic for classification

### 2. First Non-Repeating Character
- Processes a string
- Finds the first character that occurs only once
- Uses character frequency logic

### 3. Palindrome Checker
- Checks whether a string reads the same forwards and backwards
- Uses string manipulation and comparison

### 4. Reverse Customer Name
- Accepts a customer name
- Reverses the name
- Demonstrates string handling

### 5. Rock Paper Scissors
- Implements the Rock-Paper-Scissors game
- Uses conditional statements
- Determines the winner based on the choices
